# Study Quiz

Учебное Flutter-приложение из четырёх вопросов. Пользователь выбирает ответы,
может возвращаться и менять их, проверяет попытку перед завершением и получает
разбор по каждому вопросу.

## Запуск

Требуется Flutter 3.41.9

```bash
cd study_quiz
flutter pub get
flutter run 
```

## Архитектура

Clean architecture в упрощённом виде, состояние через Bloc, навигация
через go_router


## Ручная проверка

| Сценарий | Что делала | Ожидаемый результат | Фактический результат |
|---|---|---|---|
| Полностью правильная попытка | Q1 a, Q2 a, Q3 {a,b}, Q4 сначала b, потом a | 4 из 4 | 4 из 4, все вопросы с баллом 1 |
| Лишний и пропущенный вариант | Q3 = {a,b,c}, Q4 = {a} | 0 за Q3 и 0 за Q4 | 0 за Q3 и 0 за Q4 |
| Возврат и изменение | Выбрала b в Q1, перешла назад и вперёд, на экране проверки вернулась к Q1 и сменила на a | Прежний выбор виден, итог учитывает a | Выбор сохранялся при переходах, в итоге засчитан ответ a |
| Пропуск | Оставила Q2 без ответа, нажала «Завершить» | Экран проверки показывает число пропусков, завершение требует подтверждения | «Без ответа: 1», появилось окно подтверждения, после него открылся результат с 0 за Q2 |
| Повтор и читаемость | «Новая попытка»; окно 390 px, текст на шаг крупнее | Ответы очищены; варианты и кнопки видны, ничего не перекрывается | Ответы пусты, итог не перенесён; на узком экране и с крупным текстом всё читаемо |


## Журнал использования AI

Claude Sonnet 5

| Задача | Полученная помощь | Что я изменила | Как проверила |
|---|---|---|---|
| Архитектура и план работ | Предложена структура папок (domain / data / presentation), один AttemptBloc, go_router с номером вопроса в адресе, разбивка на этапы | выбрала go_router, с которым уже работала | Сверила с требованиями ТЗ: отдельная функция без виджетов, отделённый контракт Question |
| Модель Question, 4 вопроса, репозиторий | Код сущности, интерфейса и локального репозитория, пояснения по одному предложению | Сверила тексты вопросов, варианты и правильные ответы с ТЗ | Сравнение с текстом ТЗ; проверка расчёта на двух наборах ответов (результат 4 и 0) |
| Экран вопроса и роутер | Код страницы, RadioGroup для single, CheckboxListTile для multiple, кнопки навигации | принято без правок | Ручная проверка: замена выбора, сохранение при «Назад» и «Далее» |
| Экраны проверки и результата | Код страниц, диалог подтверждения, карточки разбора | принято без правок | Ручные сценарии «Пропуск», «Возврат и изменение», «Повтор» |
| Тема приложения | Стили и текста скопированы из моего прошлого проекта wordly | Строки написала заново на русском | Визуальная проверка |
